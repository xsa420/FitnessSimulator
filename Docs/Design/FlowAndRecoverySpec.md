## [FRAME] 1. 状态与输入输出语义

|---|---|
| [FRAME｜既定] 当前局 | 单一当前局；输入已解锁模板和首次计划，输出各领域初值、默认周一第1日与有效计划。新局覆盖当前局；永久历史／模板资格保留，不继承金钱、力量、物品、关系或个人计划。 |
| [FRAME｜候选基线] 事件实例 | 输入当前角色、日期锚点、配置版本、已提交状态、入口超时、已占用目标；输出开始事实、子事件进度、业务变化、耗时、明确消耗目标、正常后继与可恢复位置。配置身份用于共享次数；实例身份用于一次执行与恢复，不混用。 |
| [FRAME｜既定] 正常子事件 | 完成后保存，检查首个合法结局；复合容器结束仅汇总，不重复发效果、不额外检查。普通未完成子事件回自身起点，此前完成子事件保留。 |

## [FRAME] 2. 锚点、消耗与入口解析

[FRAME｜既定] 后半夜属于当天。解锁清晨／后半夜即时提示、本局永久保留，日结加入并在次日可用，不插入当天。首次计划在开局可编辑并于最终确认当天生效；局内修改明日起计划只在当前“晚上”锚点的安全可编辑状态开放，同日最后保存版本获准，不向用餐、日结或其他时段扩展。计划事件锚点默认中午／晚上；默认项不等于擅自删除其他合法锚点。天数循环以生效日为第1项，漏训不补、不顺延。最新工作收入与旧档兼容以§18为准。

| 候选顺序 | 锚点性质／用途 |
|---|---|
| [FRAME｜候选基线] 1 清晨（条件解锁） | 普通活动；可计划训练。 |
| [FRAME｜候选基线] 2 早餐 | 独立用餐；不计划训练，默认事件包含明确不吃选项。 |
| [FRAME｜既定] 3 上午 | 非休息日默认上班，是否休息由当日有效计划判断；赛事等优先事件占用后不补班。未解锁清晨时是首普通锚点。 |
| [FRAME｜候选基线] 4 午餐 | 独立用餐；不计划训练。 |
| [FRAME｜既定] 5 中午、6 下午 | 两个独立普通锚点；中午为计划事件默认候选，非休息日下午默认上班。每日计划总计至多一个训练锚点；优先事件占用不补班。 |
| [FRAME｜候选基线] 7 晚餐 | 独立用餐；不计划训练。 |
| [FRAME｜候选基线] 8 晚上、9 后半夜（条件解锁） | 普通活动；可训练。训练日晚上学习另读当日实际练过动作集合。 |

[FRAME｜候选基线] 排序理由：保留原四普通锚点，三餐独立且在对应主要活动前；无需增加小时模拟。非训练外层事件读取自身标准时长：普通样本1800游戏秒、餐点样本600秒；训练外层必须读取训练稿冻结的计划标准L_std，不被1800覆盖。一个外层只扣一个标准。仅用于超时分支，不禁止开组。由本流程策划维护非训练标准，训练策划维护训练标准与动作耗时；用长计划、重复休息、跳餐及5—10分钟分段实测校准，不把现实操作时间当游戏秒。

| 锚点解锁候选 | 条件、提示与验证 |
|---|---|
| [FRAME｜候选基线] 清晨 | 游戏日≥7且本局已有至少一次有效完成量≥1的训练组结算。正常子事件完成后首次同时满足即提示“已解锁清晨，明日起可安排训练”；本局保持。若D7满足，D7不插入，D8可用，可提前存入D8计划。 |
| [FRAME｜候选基线] 后半夜 | 游戏日≥14且任一动作知识≥10。首次满足提示“已解锁后半夜，明日起可安排训练；后半夜仍属于当天”；知识后来下降不收回。D14达到则D15生效。 |

[FRAME｜候选基线] 解锁理由：清晨让玩家先熟悉基础日程，后半夜提供学习后的安排空间，不增加主要人物或新成长系统。使用已有日期、有效组与知识字段，不新增任务清单。由本流程策划维护门槛；验D6/D7边界、知识9/10边界、同日计划可选次日锚点、当日不插回、日结中断后只激活一次。若玩家到日门槛时条件已满足，在该日首次正常完成节点发现并登记；不凭现实时间自动弹出。

[FRAME｜既定] 外层事件默认消耗当前锚点，子事件默认不额外消耗。显式目标支持相对日和本周星期：过滤过去目标，不滚到下周；剩余目标未解锁或已占用即不入候选；过滤后空列表为配置错误。只消耗列出目标，夹在中间的其他锚点不受影响。明确消耗餐点则不补餐。

[FRAME｜候选基线] 占用与完成分开：合法事件开始时保留其全部明确目标，随后恢复同实例仍持有这些目标，其他事件不能抢占；结束后保留消耗事实。未完成业务回起点不等于入口重抽或释放本实例预留。若存储确认失败，不能向玩家显示已开始成功。未来目标按目标日期的已生效／已确定次日解锁资格判断，不预言尚未达成的条件；本实例自己占用的当前锚点不视为与自己冲突。

| 消耗输入例 | 预期 |
|---|---|
| [FRAME｜候选基线] 周一上午事件明确消耗今天上午、下午 | 中午与午餐仍执行；下午计划训练漏训，不转移到晚上。 |
| [FRAME｜候选基线] 周三事件指定本周周二上午＋周四下午 | 过去周二忽略；周四下午若合法则仅占它，不顺延周二。 |
| [FRAME｜候选基线] 周三事件只指定本周周二上午 | 过滤为空，报配置错误；不能偷偷改成当前锚点。 |
| [FRAME｜候选基线] 明日清晨尚未解锁，事件指定该点 | 不入池；若今天已达成且明确次日开放则可引用未来生效资格。 |
| [FRAME｜候选基线] 全天学习列出当日全部剩余普通锚点 | 首普通锚点启动，三餐保留；清晨已解锁时须从清晨启动，不能上午撤销此前清晨。 |

[FRAME｜既定] 每个未消耗锚点仅解析一次第一层池，训练动态树和普通固定树共用后继执行。解析顺序：启用→条件→每局次数→冷却→占用合法性→每互斥组按配置顺序选首个合法成员→按事件标识去重→选择事件合成组→与普通事件一起加权抽取。选择组默认权重100；其他启用权重为正；禁用不能用零权重替代。事件最多属于一个互斥组。

[FRAME｜既定] 只有没有其他合法候选时用默认入口；默认无限、间隔0且必须可执行。普通事件次数是配置值，不能为方便统一改1。进入选择组时一项直接执行，多项先选中再确认、不得取消或跳过；展示不计次数，真正开始才计次数与最近触发日。相同配置跨锚点／子树引用共享统计。第3天触发、冷却2，完整跳过第4/5天，第6天可再触发；冷却0同日后续锚点可再触发。

[FRAME｜候选基线] 开始事实、选中入口和统计一起可恢复；恢复是继续同实例，不第二次开始。入口被选中后不随打开辅助页重抽；确认选项时核对合法性，若状态因已完成独立操作变化则刷新该选择组合法项，不重抽整个第一层池。必需固定后继此时非法则报错；可选分支必须显式配合法兜底，不把错误当跳过。

[FRAME｜候选基线] 子树调用只推进已有实例路径；次数用共享配置身份，进度用当前实例路径。固定后继不是重新进第一层池；动态训练生成时锁定当天有效计划、动作顺序、组配额，次日计划编辑不能改当前树。结束当前动作只能在训练结算后发生；跳过该动作余组后继续后续合法动作。推进锚点终止当前锚点余下流程；不能绕过已保存待结算组。

## [FRAME] 3. 超时与有限事件样本

[FRAME｜既定] 耗时只计实际完成次数×动作每次耗时及实际执行休息，其他事件按明确配置时间；界面停留／动画快慢不计。超时作为下一锚点第一层输入，不自动消耗后续时段。

[FRAME｜候选基线] 当前入口总游戏耗时H、标准L，输出超时秒max(0,H−L)及是否超时；下一实际未消耗锚点读取一次。训练入口H含有效次耗时、已提交休息及明确非训练后继加时；L仅为冻结计划L_std，后继额外耗时不再增加另一份标准。训练模块可报告训练部分耗时与参考超时，外层只用累计H和该L最终算一次，不再相加训练超时。被明确消耗的锚点不抽入口，不吞掉该输入；树内汇总只汇总已记耗时。下一入口按自身实际耗时产生自己的超时，不滚动累积旧债务；当天最后锚点输出只记入日结展示，次日首锚点从0开始。理由：不引入未确认的跨日补时系统。此处传递范围由本流程策划调整并与训练方共验。

[FRAME｜候选基线] 算例：上午标准1800秒，执行1960秒，则午餐收到超时160秒；午餐仍可选吃或不吃。若午餐已明确消耗，中午接收160秒；中午事件自身耗时300秒、标准1800，下一锚点输入0。额外休息180秒增加训练时间180秒，不因玩家看手机五分钟多收时间。

[FRAME｜候选基线] 训练算例引用训练稿：卧推2×6、弯举2×8，工作136秒＋3次中休270秒，L_std=406。完整训练加一次长休使训练H=586，若后继另明确耗时60秒，则外层H=646，超时240秒；不能按1800得0，也不能把训练超时180再加外层超时240得420。原1800/1960例仅为非训练外层通用验收夹具。

### [FRAME] 学习与商店实际耗时补齐

[FRAME｜候选基线] 原稿缺少下列实际加时，现为应用接入补齐；不是从标准L自动推导H。单位统一游戏秒，界面停留、现实操作速度不影响。全天学习为明确跨多普通锚点的外层事件，其专用L同时明确，覆盖普通单锚点样本L=1800；不改变训练L_std或餐点计时。

|---|---|---|
| [FRAME｜候选基线] 全天学习完成 | 1800×N；N为事件开始时锁定的当日明确消耗普通锚点数量，不含三餐。基础四点为7200，另解锁清晨或后半夜各加1800，两者均有为10800。 | 本事件专用L=1800×N，开始锁定N及H/L配置；学习完成时知识与H同次提交一次，被消耗后续锚点不再各自加时。未完成学习恢复不扣学习H，已完成前置笔记保留自己的提交。 |
| [FRAME｜候选基线] 晚间学习完成 | 900 | 外层L=1800；知识与900秒同次提交。后续笔记操作显式加时0，不重复计学习时间。 |

[FRAME｜候选基线] 理由：全天学习的主要代价是占用所有普通活动机会，按每普通锚点1800秒记账并给予同等专用时间预算，避免正常全天学习必然向保留餐点传递超时；晚学900秒体现较短单次活动；到店统一300秒表示一次访问成本，离开与交易0避免购买数量驱动加时。以上仅游戏候选，不表示现实学习或逛店时长。知识量不随N增加，仍为各动作12；多解锁锚点增加的是被占机会和时间记录，不额外发知识。

[FRAME｜候选基线] 算例/验收：四普通点全天学习H7200/L7200，下一未消耗餐点收到超时0；仅清晨解锁时H9000/L9000。晚学后用或不用一本笔记均H900。商店进入→购买三笔→退出→重开，H仍300；进入已存/离开未完退出也仅300。若商店后继明确再耗1600，则总H1900、超时100，只算一次。检查完成前后中断、同命令/新ID同访问语义重试、两店及各actor隔离；字段不能用界面进出次数累计。由本流程策划维护时间参数，生活策划维护学习/交易效果，长路线报告检验总时间和超时分支后再调，不改变已有合法提交。

## [FRAME] 7. 存档、日志与损坏流程

[FRAME｜既定] 当前局为覆盖式自动保存；永久历史与模板资格独立保留，旧局完整玩家过程不供浏览。当前局各日有效记录包含已见文本、已选选项、实际变化及来源，不展示未选分支／隐藏判定，不提供回退重选或搜索筛选。诊断日志按局保留至主动清理，同局继续追加会话段，作废链关联恢复点。

[FRAME｜候选基线] 每次恢复先识别最近有效业务边界，再处理其待结算／待检查／待演出／待日切后继；不能从界面当前页猜流程。存储成功返回前不得显示可离开后的最终业务成功；存储失败保留可重试状态，不能再发同一奖励。技术可采用多阶段持久化，但玩家始终只得到完整已提交前态或完整后态。

## [FRAME] 8. 配置与条件共性及诊断

[FRAME｜既定] 条件支持全部满足、任一满足、不满足及嵌套，读取最新有效日期／状态／经历；条件判断无副作用，持有物品不暗扣。范围不允许另加累计获得／使用物品玩法统计。配置错误不能默认成功、默认零或静默跳过。

[FRAME｜候选基线] 编辑校验：非空稳定引用；合法上下文与字段类型／单位；条件组合子项非空（防空ALL意外真）；正整数次数或明确无限；冷却非负整数；启用权重>0；互斥最多一组且顺序明确；每锚点默认入口有效无限／0冷却；必需后继存在；消耗语法／去过去后空列表；训练控制只在结算后；有限子树不得无条件环；角色资源边界；结局顺序唯一、演出不递归。概率边界／动作贡献和／评委人数等由领域校验器提供，公共配置汇总报告。

[FRAME｜候选基线] 运行校验：动态条件不再成立、目标占用变化、实际默认入口不可执行、必需后继非法、组结果与计划／版本不匹配，均阻止本错误步骤提交并保留最近有效点。报错至少定位配置、字段／条件路径、事件实例、角色、日期锚点与原因，面向玩家的文本不得泄露隐藏条件。合法无其他候选与默认配置错误必须可区分。

[FRAME｜候选基线] 随机在业务决策点产生并保存；刷新界面／打开角色页不抽；同存档同操作同结果。事件入口、伤病、评委、店货、人物策略可由程序选择隔离方式，但不得让玩家翻页改变人物赛分。验证记录必须分正式玩家输入、正式人物策略结果、测试注入；注入仅证明下游规则，不证明八小游戏可操作或人物策略真实完成。
